## 0.1.0 (unreleased)

Initial release.

- `@attrichart/core`: framework-agnostic SVG engine. N stages, overlap on any stage, `reach` and `fractional` attribution modes, hover path isolation, tooltips, events, responsive sizing, strict data validation.
- `@attrichart/vue`: Vue 3 component with Vuetify 3 theme integration and SSR-safe mounting.
- `@attrichart/react`: React component (React 18 or 19), SSR-safe, handlers swappable without re-mounting the chart.
