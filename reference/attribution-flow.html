Campaign attribution flow prototype

Source → traffic → conversion, with shared attribution drawn as overlap. The campaign column shows reach, so its segments sum past 100% because multi‑touch users appear in every campaign that touched them. Flow consolidates to true unique counts from the traffic column rightward. Hover any ribbon to follow one path.

The left edge is where overlap lives: a user touched by two campaigns is drawn from both source segments, and where those translucent ribbons stack they darken, which is the shared attribution made literal. As each ribbon moves right it merges into one body, so the traffic and conversion columns stay honest 100% partitions and the widths there map to real visitors, not inflated touch counts.
