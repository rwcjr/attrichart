AttriChart

A Sankey-style flow chart for journeys with overlapping membership. Standard Sankey libraries force every unit onto exactly one path, so multi-touch attribution gets double-counted, fractionally split, or flattened to single-touch. AttriChart treats the overlap explicitly: the overlap stage renders reach and its translucent ribbons darken where membership is shared, while downstream stages consolidate to true unique counts.

GitHub @attrichart/core @attrichart/vue

Marketing attribution, reach mode (default)

4,000 unique users, 5,400 total reach. The campaign column sums past 100% because multi-touch users appear in every campaign that touched them. Where ribbons stack and darken, attribution is shared. Hover any ribbon to isolate one cohort's full path.

Fractional mode

The same data with attributionMode: "fractional". Shared cohorts split their width evenly across campaigns, so every column stays strictly additive. Tidier arithmetic, less visual emphasis on multi-touch.

Not just marketing, not just three stages

A streaming service journey across four stages with the overlap stage in the middle: subscribers watch several genres, so that column shows reach while its neighbors stay clean partitions.

Install

npm install @attrichart/core
# or, in a Vue 3 app
npm install @attrichart/vue
import { AttriChart } from '@attrichart/core';

const chart = new AttriChart(document.querySelector('#chart'), {
  stages: [
    { id: 'campaign', overlap: true, nodes: [{ id: 'search' }, { id: 'social' }] },
    { id: 'conversion', nodes: [{ id: 'purchase' }, { id: 'none' }] },
  ],
  records: [
    { value: 500, membership: { campaign: ['search'], conversion: 'purchase' } },
    { value: 200, membership: { campaign: ['search', 'social'], conversion: 'purchase' } },
    { value: 300, membership: { campaign: ['social'], conversion: 'none' } },
  ],
});
chart.render();
